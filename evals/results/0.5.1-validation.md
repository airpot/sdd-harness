# Version 0.5.1 Distribution Validation

The repository root is now the skill directory, matching the requested root-installable format.
It contains `SKILL.md`, `scripts/`, `references/`, and `assets/`.
The repository can be cloned directly into a discovered skill directory.
The scripted installer and ZIP contain only the thirteen portable skill files.

- Exclude README, Git metadata, tests, specifications, evaluation records, distributions, and unrelated skills from scripted installation.

- Keep refusal to overwrite different installed content or existing ZIP files.
- Update installation commands, source references, and version metadata.

The accepted 0.5.0 development workflow is unchanged.
Only version metadata, installation guidance, and the installation script changed within the portable payload.
The workspace preservation script and all workflow, delivery, recovery, and writing references remain byte-identical to 0.5.0.
The [0.5.0 behavioral evidence](0.5.0-validation.md) retains that scope. It was not rerun as new 0.5.1 evidence.

## Limits

These checks establish local distribution and installation behavior. They do not prove automatic selection in every agent.
Direct cloning retains repository development files. Use the installer or release ZIP for the filtered thirteen-file tree.
Git checkout line endings can differ from the build workspace. Payload hashes record raw distribution bytes.
Complete ASD-STE100 compliance remains unverified.
The review could not create a Windows symbolic-link fixture. Python 3.10/3.11 junction behavior remains unverified.
