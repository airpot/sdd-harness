# Version 0.6.0 Validation

Version 0.6.0 adds optional subagent work with main-agent acceptance and recovery responsibility.
Independent development remains the default.
The portable package adds one conditional reference and reuses existing task and handoff records.
Installed scripts remain byte-identical to released 0.5.1.

## Accepted behavior

- Select delegation by independent value, dependencies, context needs, and coordination cost.
- Provide a bounded task with accepted requirements, exact basis, necessary context, allowed actions, evidence, and limits.
- Check actual host inheritance, permissions, continuation, and execution controls.
- Retain main-agent responsibility for complete acceptance and combined integration.
- Assess actual artifacts and evidence. Keep partial, failed, and unrun work visible.
- Bound worker effort, nested delegation, retries, and review disagreement.
- Preserve outstanding workers and pending decisions during chat replacement.
- Distinguish returned output, acceptance, resident context, active execution, and resource closure.
- Preserve descendant results and check stopped execution before reassignment or resource removal.
- Reject automatic application of superseded results and unauthorized retries of unknown external effects.

The entry routes to [subagent rules](../../references/subagents.md) only when relevant.
No mandatory team, coordination service, task database, model tier, global settings, or extra release authority was added.
README remains Chinese. Execution instructions and internal records use STE-guided English.
