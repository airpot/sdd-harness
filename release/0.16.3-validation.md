# 0.16.3 验证摘要

对已发布和安装的 0.16.2 作独立复审。源码 README 的安装说明修正、克隆目录与 ZIP 安装，以及发布包与本机文件逐项核对通过。

- 全仓测试 566 项：563 项通过，3 项条件跳过，无失败或错误。
- 0.16.2 的最后一关严格 gate 可在早先的报告缺失或失配时释放 RC；生产选择仍会拦截该候选。新版复核全部报告，有缺陷时保留槽位和历史，并可依现有授权规则处置。
- 0.16.2 允许用空文件恢复未决任务命令，释放该命令取得的资源。新版拒绝空白或非 UTF-8 文本证据并保留占用；记录内容是否属实仍由项目方核实。
- 最终改动的两轮独立复审无未解决发现。30 个便携文件与 ZIP、解压件和临时安装逐项一致。

验证使用 Windows 和隔离 CLI fixture。未执行生产部署或激活原生 hook。
