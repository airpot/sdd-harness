# 0.16.4 验证摘要

独立复审已发布和已安装的 0.16.3，关注多个窗口和 worktree 并发时的锁保留与交接。

- 全仓测试 578 项：575 项通过，3 项条件跳过，无失败或错误。
- 旧版可在 checkout 改指另一 registry 后，用同名请求完成另一仍在运行的 gate，导致提前释放 RC。新版的任务命令、交付命令及共享 hook 检查回调只访问准入时的 registry 和执行记录。
- 新处置证据绑定操作 ID；新退役授权与证据绑定登记 ID。旧版已保存的记录仍可在原 registry 按相同证据重读。
- 发布和验证使用具体登记 ID；新发布授权须匹配构件摘要。已准入的旧发布可恢复并验证。
- 用真实 CLI 验证两个 Git worktree 共用 registry 时的超时、迟到回调、恢复和退役重放，后继持有的资源不受影响。
- 独立复审发现 Windows 扩展路径回写问题，末次修正经定向 CLI 和全仓测试验证，未另作整轮独立复审。30 个便携文件与 ZIP、解压件和临时安装逐项一致。

验证使用 Windows 和隔离 CLI 夹具。未执行生产部署或启用原生 hook；共用实际资源的参与者仍须使用同一受控 registry 或项目后端。
