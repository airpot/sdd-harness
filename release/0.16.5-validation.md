# 0.16.5 验证摘要

独立复审已发布和安装的 0.16.4。已有 registry 的后继锁、迟到回调、旧记录重放、Windows 扩展路径和旧发布准入的定向检查通过。

- 全仓测试 601 项：598 项通过，3 项条件跳过，无失败或错误。
- 旧版在目标 registry 尚未初始化时拒绝旧请求，却留下空数据库，导致后续检查异常。未观察到后继锁被误释放。
- 新版只有不依赖既有记录的顶层任务领取和候选登记可以初始化 registry；依赖既有记录的命令或回调不会创建数据库。后续检查和本地 hook 模式不因拒绝而改变。
- 独立复审发现的父任务和依赖建库问题已修正，并通过定向 CLI 与最终全仓测试；末次修正未另作整轮独立复审。Windows 扩展路径和本机设备路径均经 CLI 检查。分发包使用上一版已核验的打包工具。30 个便携文件与 ZIP、解压件和临时安装逐项一致。

验证在 Windows 上使用真实 CLI 和隔离夹具。未执行生产部署或激活原生 hook。
